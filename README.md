# Prep Simulator for LCAT

A free Android app by [HomiLabs](https://homilabs.org) for the LUMS Common Admission Test (LCAT): 20 full mock exams with four separately timed sections (Verbal 1, Verbal 2, Math 1, Math 2), a question bank sorted by section, content domain and topic, an explanation for every question, and a Guide & Rules section. Independent practice material, not affiliated with LUMS.

- App: Flutter, in `lib/`. Project notes: `CLAUDE.md`.
- Question bank: `content/bank/`, built into `assets/data/` by `tool/build_content.py`.
- Website: `website/`, for https://lcat.homilabs.org.
- Release and hosting: `docs/release-and-hosting.md`.
